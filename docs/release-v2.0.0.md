# powerfit v2.0.0

**Version DOI:** [10.5281/zenodo.24047266](https://doi.org/10.5281/zenodo.24047266)  
**All-versions concept DOI:** [10.5281/zenodo.19673557](https://doi.org/10.5281/zenodo.19673557)  
**Git tag:** [v2.0.0](https://github.com/DeloneCommons/powerfit/tree/v2.0.0)

Version 2.0.0 provides a substantially revised mathematical manuscript on
fixed-site inverse fitting of power-diagram weights, seven article figures, and
streamlined build and reproducibility documentation.

The Zenodo archive contains `powerfit-v2.0.0.zip`: the complete tagged source
tree, including experimental configurations, numerical results, molecular data,
and a compiled article PDF at `manuscript/manuscript.pdf`.

The experimental protocols, numerical results, and scientific dependencies
remain unchanged from [v1.0.0](https://doi.org/10.5281/zenodo.19673558).
The reported calculations used
[pyvoro2 0.6.3](https://doi.org/10.5281/zenodo.19143984).
