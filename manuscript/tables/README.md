# Tables

Editable manuscript-side table fragments live here. Run
`python scripts/build_manuscript_tables.py` from the repo root for a targeted
table-only refresh of the generated fragments from the archived result
summaries. For the canonical end-to-end manuscript build, use
`bash scripts/build_manuscript_pdfs.sh`.

## Main-text tables currently used by `manuscript.tex`

| Table file | Generator function | Main archived inputs |

| `table_J1_dataset_audit.tex` | `table_j1_dataset_audit()` | `results/qtaim_main/J1_dataset_audit/` |
