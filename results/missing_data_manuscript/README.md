# Experiment C manuscript-figure results

This directory stores the dense missing-data sweep used only for the manuscript figure of Experiment C.

Files:
- `runs.csv` — dense per-instance benchmark table;
- `summary.csv` — aggregate metrics by dimension, site count, and retained-edge fraction;
- `metadata.json` — configuration snapshot and runtime provenance;
- `manuscript_analysis/` — manuscript-facing aggregated figure assets, including the final composite figure and its summary data.
