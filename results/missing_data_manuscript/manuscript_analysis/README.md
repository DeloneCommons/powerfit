# Experiment C manuscript-analysis artifacts

This directory stores the manuscript-facing derived artifacts for the dense
missing-data sweep used in Figure 1.

Files:
- `figure_C_missing_data_composite.png` / `.pdf` — final composite manuscript
  figure with separate RMSE and connected-rate profile panels plus the 2D/3D
  phase maps;
- `alignment_profile.png` / `.pdf` — profile-only companion figure with the same
  separated scaling;
- `transition_heatmap.png` / `.pdf` — heatmap-only companion figure;
- `summary.csv` / `summary.tex` — aggregated data behind the manuscript-facing
  plots.
