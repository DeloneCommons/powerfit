# Experiment F results

This directory stores the archived benchmark outputs for **Experiment F (periodic wrong-image stress tests)**.

Files:
- `runs.csv` — row-wise benchmark outputs;
- `summary.csv` — aggregate periodic/image-handling metrics used for the manuscript table;
- `metadata.json` — configuration snapshot and runtime provenance.

The archived benchmark now sweeps multiple authoritative wrong-image corruption
fractions and records replicate-spread summaries for the main periodic
image-choice, wrong-shift, and reconstruction diagnostics.
