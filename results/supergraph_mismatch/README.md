# Experiment H results

This directory stores the archived benchmark outputs for **Experiment H (structured misspecification under supergraph uncertainty)**.

Files:
- `runs.csv` — row-wise outputs for one-shot fitting and realization-aware self-consistent refinement;
- `summary.csv` — aggregate metrics by candidate graph, mismatch amplitude, method, and dimension;
- `metadata.json` — configuration snapshot and runtime provenance;
- `analysis/summary.csv` / `trend_summary.csv` — manuscript-facing aggregates for tables and text.
