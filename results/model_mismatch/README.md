# Experiment G results

This directory stores the archived benchmark outputs for **Experiment G (structured model mismatch)**.

Files:
- `runs.csv` — row-wise benchmark outputs on the exact support oracle, including the ordinary Voronoi midpoint baseline columns;
- `summary.csv` — aggregate metrics by geometry family, mismatch law, amplitude, and dimension;
- `metadata.json` — configuration snapshot and runtime provenance;
- `analysis/trend_figure.png` / `.pdf` — manuscript-facing trend figure;
- `analysis/trend_summary.csv` — aggregated statistics behind the trend figure;
- `analysis/moderate_eta_table.tex` / `high_eta_table.tex` — baseline-aware comparison tables at representative mismatch strengths.
