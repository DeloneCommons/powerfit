# Experiment G analysis artifacts

This directory stores the manuscript-facing derived artifacts for the structured
model-mismatch benchmark.

Files:
- `trend_figure.png` / `.pdf` — final model-mismatch trend figure;
- `trend_summary.csv` / `.tex` — aggregated statistics behind the trend figure;
- `summary.csv` / `.tex` — baseline-aware aggregate summary by geometry, law, amplitude, and dimension;
- `moderate_eta_table.tex` / `high_eta_table.tex` — representative baseline comparison tables at $\eta=0.20$ and $\eta=0.50$.
