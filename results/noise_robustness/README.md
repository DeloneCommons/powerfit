# Experiment B results

This directory stores the archived benchmark outputs for **Experiment B (noise and contamination response)**.

Files:
- `runs.csv` — row-wise benchmark outputs;
- `summary.csv` — aggregate metrics used for the manuscript table;
- `metadata.json` — configuration snapshot and runtime provenance.

The archived benchmark now compares the baseline squared fit to a Huber variant
on the same exact support and includes replicate-spread summaries for the main
measurement, algebraic, and realization-aware diagnostics.
