# proatomic reference-data scaffold

This directory contains the isolated-atom inputs and derived tables used for
the project's proatomic separator baseline.

## Current scope

1. `atom_manifest.csv`
   - explicit isolated-atom SCF inputs for the supported element set
     (`H, C, N, O, F, S, Cl`);
   - one row per atomic reference state;
   - row-specific `charge`, `multiplicity`, `basis`, `xc`, and output
     `molden_path`.

2. `molden/`
   - isolated-atom Molden files written by
     `scripts/qtaim/run_pyscf_atomic_singlepoint.py`.

3. `radial/`
   - raw Multiwfn outputs and aggregated radial tables generated by
     `scripts/qtaim/run_multiwfn_radial_density.py`;
   - `rdf_grid.csv` stores the exported Multiwfn RDF on an Angstrom grid;
   - `radial_density_grid.csv` stores the exported spherically averaged
     electron density on the same Angstrom grid;
   - `radial_density_meta.json` records the exact protocol and units.

4. `pairlaw/`
   - frozen local separator lookup tables generated by
     `scripts/qtaim/build_proatomic_separator_lookup.py`;
   - `separator_lookup.csv` stores the promolecule-minimum separator position
     for each ordered element pair on a fixed distance grid;
   - `separator_lookup.meta.json` records lookup-grid settings and provenance.

5. root-level run logs
   - `atomic_pyscf_run_summary.csv`
   - `multiwfn_radial_run_summary.csv`
   - optional error logs if a stage fails.

## Recommended current workflow

Generate isolated-atom Molden files:

```bash
python scripts/qtaim/run_pyscf_atomic_singlepoint.py \
  data/proatomic/atom_manifest.csv \
  --nproc 4
```

Build radial tables with Multiwfn:

```bash
python scripts/qtaim/run_multiwfn_radial_density.py \
  data/proatomic/atom_manifest.csv \
  --nproc 4
```

Build the frozen pair-law lookup:

```bash
python scripts/qtaim/build_proatomic_separator_lookup.py
```

Default radial settings for the Multiwfn stage are intentionally fixed to:

- `r = 0.0 .. 5.0 Å`
- `501` radial points
- `2030` shell integration points
- electron density as the real-space function

These defaults are meant for the first proatomic baseline and can be overridden
from the command line if needed.

## Manifest columns

Required columns:

- `element`
- `molden_path`

Common optional columns:

- `species_key`
- `charge`
- `multiplicity`
- `basis`
- `xc`
- `notes`

Relative paths are resolved against the location of `atom_manifest.csv`.
